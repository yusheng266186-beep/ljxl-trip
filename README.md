# 丽江 × 香格里拉 · 六日慢旅行手册

一份移动端优先的单文件旅行网页，面向成都出发的丽江—香格里拉六天五晚双人慢度假。

> 在线页面：[打开六日慢旅行手册](https://yusheng266186-beep.github.io/ljxl-trip/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/ljxl-trip)

## 行程概况

- 出发地：成都；
- 目的地：丽江、香格里拉；
- 时间：2026年8月6日—8月11日；
- 类型：双人慢度假；
- 住宿：丽江古城花间府·植梦连续入住；
- 设计原则：每天只设置一个主场景，保留休息和天气调整空间。

这份手册不是“景点越多越好”的打卡表，而是把文化、摄影、美食、安全和预约事项放在一起，让旅行过程中少做临时决策。

## 页面内容

### 行程总览

快速查看六天每日主题、交通安排和主要场景。时间轴卡片可以展开，查看：

- 详细安排；
- 内容或餐饮；
- 交通方式；
- 备注和备用方案。

### 文化预习

提供丽江、香格里拉及沿线文化观察线索，帮助使用者在旅行前建立背景知识，到达现场后更容易理解建筑、信仰、饮食和生活方式。

### 摄影指南

按照地点和氛围整理拍摄建议，包括：

- 光线；
- 构图；
- 建筑与街巷；
- 人物和双人合照；
- 雨天与室内替代方案。

### 美食清单

整理云南地方风味和旅行中适合尝试的食物，包含点餐方向、口味和现场选择建议。餐厅营业、价格和排队情况需要出发前重新确认。

### 备选方案

- 天气不好时的室内或短距离方案；
- 身体状态下降时的缩短方案；
- 交通临时变化时的替代思路；
- 预约失败或景点关闭时的替换方案。

所有备选遵循“替换，不叠加”原则，避免因为临时调整把行程重新塞满。

### 安全与出发清单

- 高原旅行注意事项；
- 天气和交通预警；
- 预约、车票、证件和行李清单；
- 可勾选的出发准备事项；
- 停损线和休息建议。

## 交互特点

- 移动端优先的响应式布局；
- 顶部章节导航；
- 搜索按钮和搜索覆盖层；
- 输入关键词后直达对应章节；
- 时间轴和内容区域可展开；
- 清单状态保存到当前浏览器本地；
- 不需要登录，也没有服务器端账户；
- 单文件部署，适合手机直接打开。

## 使用方式

### 在线使用

打开 Pages 地址即可使用：

    https://yusheng266186-beep.github.io/ljxl-trip/

### 本地使用

由于页面是单文件，可以直接打开 index.html。若要确保网络字体和页面资源加载稳定，建议运行：

    python -m http.server 8080

然后访问：

    http://localhost:8080/

### 手机使用

- 把在线地址保存到浏览器收藏夹；
- 也可以把文件发送到手机后用浏览器打开；
- 使用清单时尽量保持同一个浏览器和同一个页面地址；
- 清除浏览器站点数据后，本地勾选可能会消失。

页面依赖的视觉资源和部分字体可能通过远程地址加载，完全无网络环境下可能出现字体或图片降级。

## 修改手册内容

由于项目是单文件结构，内容和样式都在 index.html 中。修改时建议：

1. 先搜索章节标题或导航锚点；
2. 修改正文时保留现有 section、id 和按钮结构；
3. 修改时间轴后同步更新总览和备选方案；
4. 修改日期、车次、酒店或预算后统一搜索旧信息；
5. 检查搜索功能是否仍能找到新内容；
6. 在手机宽度下测试折叠、搜索和清单；
7. 提交前确认没有遗留过期的旅行日期和价格。

## 旅行信息提示

天气、车次、酒店服务、景区开放、预约、价格和餐厅营业状态都可能变化。页面中出现的具体日期、交通和预算是规划参考，不替代官方实时信息。

高原旅行时请关注个人身体状态。出现持续头痛、恶心、胸闷、明显乏力或其他异常，应停止赶行程，优先休息并根据需要寻求医疗帮助。
